# Paseo HTTP Tunnel v0.2.0 Release Notes

Paseo HTTP Tunnel **v0.2.0** brings major transport-layer performance improvements for streaming and request startup, alongside a refined multi-host management experience.

---

## Key Highlights

- **Pre-warmed Encrypted Channels**: Prepares up to two short-lived encrypted channels per Egress, reducing Relay and E2EE handshake work when a prepared channel is available.
- **Sliding Flow-Control Window**: Advances the $8 \times 64\text{ KiB}$ window immediately upon acknowledging the oldest block, eliminating avoidable pauses during SSE streaming and large file transfers.
- **Enhanced Multi-Host Workflow**: Documents the top-right Host Picker pattern for effortless cross-host Ingress-to-Egress binding.
- **Reproducible Benchmarks**: Introduces comprehensive synthetic and real-world LLM streaming benchmarks ([view report](https://github.com/lyhu/paseo-plugin-tunnel/blob/v0.2.0/docs/benchmark.md)).
- **Hardened Agent Prompts**: Standardizes installation prompts for AI agents to enforce Git sources, tracked-ref verification, and post-install health checks.
- **UI Diagnostics**: Displays the plugin version in the footer and provides clear connectivity status indicators.

### Performance at a Glance (Real Relay Fixture)

| Benchmark Metric | v0.1.x Baseline | v0.2.0 | Improvement |
| :--- | :---: | :---: | :---: |
| **TTFB (256 B Header)** | 442.69 ms | **82.44 ms** | **-81.4%** |
| **1 MiB Payload Transfer** | 2416.57 ms | **1348.10 ms** | **-44.2%** |
| **SSE First Data Chunk** | 427.99 ms | **101.57 ms** | **-76.3%** |

The fixed-load experiment measured response-header arrival, not handshake time in isolation. Each round waited one second for preconnections to become ready; both transport optimizations were enabled. These few sequential samples do not establish a fixed improvement for other deployments or cold requests.

## Installation and Upgrade

### Fresh Installation (Pinned Tag)

```bash
paseo plugin install lyhu/paseo-plugin-tunnel --ref v0.2.0
```

### Upgrade Existing Installation (Tracking `main`)

```bash
paseo plugin update http-tunnel
paseo plugin status http-tunnel
```

> [!NOTE]
> Existing configuration and keys at `$PASEO_HOME/tunnel/config.json` are fully preserved. Updating reloads the plugin and can interrupt active requests; it does not require restarting the primary Paseo daemon.
