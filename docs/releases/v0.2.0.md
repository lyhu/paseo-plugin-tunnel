Paseo HTTP Tunnel 0.2.0 improves request startup and streaming behavior, and makes cross-host setup easier to follow.

## Highlights

- Prepares up to two short-lived encrypted channels per Egress, reducing Relay and E2EE handshake delay when a prepared channel is available.
- Advances request and response flow-control windows as soon as the oldest block is acknowledged, reducing avoidable pauses in SSE and larger transfers.
- Shows the selected management Host clearly and documents the upper-right Host picker workflow from Ingress creation to Egress import.
- Adds reproducible transport and Anthropic-compatible SSE benchmarks with aggregate-only results.
- Strengthens Git installation guidance so Agent-assisted installs verify `source=git`, the tracked ref, and the update command.
- Displays the plugin version in the management page footer and uses friendlier wording for approved service connections between trusted hosts.

In the documented real-Relay fixture, median Tunnel response-header time for a 256-byte response decreased from 442.69 ms to 82.44 ms. Median total time for a 1 MiB response decreased from 2416.57 ms to 1348.10 ms. Results vary with Relay distance, network conditions, and upstream service behavior; see the [benchmark report](https://github.com/lyhu/paseo-plugin-tunnel/blob/v0.2.0/docs/benchmark.md) for the method and limitations.

## Install or update

Install this release from GitHub:

```bash
paseo plugin install https://github.com/lyhu/paseo-plugin-tunnel --ref v0.2.0
```

Update an existing Git-managed installation that follows `main`:

```bash
paseo plugin update http-tunnel
paseo plugin status http-tunnel
```

Existing Tunnel configuration remains in `$PASEO_HOME/tunnel/config.json`. Updating reloads the plugin and may interrupt active Tunnel requests; it does not require restarting the main Paseo daemon. Paseo compiles the plugin from source, so this release does not require a precompiled archive or npm package.

Full details are available in the [changelog](https://github.com/lyhu/paseo-plugin-tunnel/blob/v0.2.0/CHANGLOG.md) and [usage guide](https://github.com/lyhu/paseo-plugin-tunnel/blob/v0.2.0/README.md).
