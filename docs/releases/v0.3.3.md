# Paseo HTTP Tunnel v0.3.3 Release Notes

Paseo HTTP Tunnel **v0.3.3** moves the plugin onto the Paseo 0.10.3 plugin SDK and raises the host requirement to Paseo **0.10.3**. Hosts on Paseo 0.8 through 0.10.2 must upgrade their Paseo installation before this plugin will install or update.

---

## What Changed

- **Paseo SDK upgraded to 0.10.3.** `@getpaseo/plugin`, `@getpaseo/client`, and `@getpaseo/relay` move from 0.8.0 to 0.10.3, along with the regenerated `npm-shrinkwrap.json`.

- **`requirements.paseo` raised to `>=0.10.3`.** Paseo refuses to install or load a manifest whose host requirement it cannot satisfy, so an older host now fails loudly with Paseo's own upgrade diagnostic instead of loading the plugin and failing at runtime.

  > This is a breaking change for the host side. If you manage more than one host, every host running this plugin must be on Paseo 0.10.3 or newer — including hosts that only run the daemon.

- **`scripts/verify-local.mjs` adapted to the 0.10.3 client API.** `connectToDaemon` now takes a target descriptor:

  ```js
  connectToDaemon({ target: { kind: "endpoint", host: "127.0.0.1:6767" } });
  ```

---

## What Was Added

- **`index.client.test.ts`.** Covers the client contribution contract Paseo validates at load time: the contribution id shape, sidebar item registration, and surface registration. The test stubs `client/tunnel-view` so it asserts the contribution surface rather than the React tree.

## Compatibility

| Component | Requirement |
| :--- | :--- |
| Paseo CLI & daemon (npm source) | **0.10.3 or newer** |
| Paseo CLI & daemon (Git source) | **0.10.3 or newer** |
| Node.js (daemon process) | 22 or newer |
| npm (daemon host, for the manifest `build`) | 10 or newer |
| Plugin SDK | `@getpaseo/plugin`, `@getpaseo/client`, `@getpaseo/relay` **0.10.3** |

## Installation and Upgrade

### Fresh Installation

```bash
paseo plugin install npm:paseo-plugin-tunnel
```

Git source, pinned to this release:

```bash
paseo plugin install lyhu/paseo-plugin-tunnel --ref v0.3.3
```

### Upgrade Existing Installation (Tracking `main`)

Upgrade the Paseo host to 0.10.3 or newer first, then:

```bash
paseo plugin update http-tunnel
paseo plugin status http-tunnel
```

> [!NOTE]
> Existing configuration and keys at `$PASEO_HOME/tunnel/config.json` are preserved. Updating reloads the plugin and can interrupt active requests; it does not require restarting the primary Paseo daemon.

> [!IMPORTANT]
> On a host below Paseo 0.10.3, `paseo plugin update` is expected to fail with a host version error. That is the manifest requirement doing its job — upgrade Paseo, then update the plugin.
