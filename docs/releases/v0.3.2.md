# Paseo HTTP Tunnel v0.3.2 Release Notes

Paseo HTTP Tunnel **v0.3.2** publishes the plugin to npm, so Paseo 0.9 and newer can install it without cloning from GitHub. It also fixes the lockfile packaging that would otherwise break every npm install.

---

## What Was Added

- **npm publication as `paseo-plugin-tunnel`.** Paseo 0.9 and newer install from the registry:

  ```bash
  paseo plugin install npm:paseo-plugin-tunnel
  ```

  Paseo 0.8 keeps installing from GitHub with `paseo plugin install lyhu/paseo-plugin-tunnel`. The two paths ship identical pinned dependency versions.

- **Package metadata.** `package.json` now declares `files`, `author`, `repository`, `bugs`, `homepage`, and `keywords`, so the published package and the Paseo registry listing carry the same identity.

---

## What Was Fixed

- **The manifest `build` would have failed on every npm install.** The plugin's `paseo-plugin.json` runs `npm ci`, which requires a lockfile in the install directory, but npm hard-excludes `package-lock.json` from published tarballs. A `paseo plugin install npm:...` would have aborted during dependency installation.

  The lockfile is now tracked as `npm-shrinkwrap.json`, which npm *does* ship inside the published package. Git and npm installs therefore resolve the same locked versions, and the manifest keeps using reproducible `npm ci` instead of a floating `npm install`.

  > This also corrects an earlier claim in the installation guide that the manifest `build` runs on Git installs only. Paseo executes `build` for npm sources as well; a directory install is the only case that skips it.

## Compatibility

| Component | Requirement |
| :--- | :--- |
| Paseo CLI & daemon (npm source) | **0.9.0 or newer** |
| Paseo CLI & daemon (Git source) | **0.8.0 or newer** |
| Node.js (daemon process) | 22 or newer |
| npm (daemon host, for the manifest `build`) | 10 or newer |
| Plugin SDK | `@getpaseo/plugin`, `@getpaseo/client`, `@getpaseo/relay` **0.8.0** |

## Installation and Upgrade

### Fresh Installation

Paseo 0.9 or newer:

```bash
paseo plugin install npm:paseo-plugin-tunnel
```

Paseo 0.8:

```bash
paseo plugin install lyhu/paseo-plugin-tunnel --ref v0.3.2
```

### Upgrade Existing Installation (Tracking `main`)

```bash
paseo plugin update http-tunnel
paseo plugin status http-tunnel
```

> [!NOTE]
> Existing configuration and keys at `$PASEO_HOME/tunnel/config.json` are preserved. Updating reloads the plugin and can interrupt active requests; it does not require restarting the primary Paseo daemon.
