# Project maintenance

- Update `CHANGLOG.md` for user-visible features, fixes, security changes, and installation changes. Keep entries concise and group new changes under `Unreleased`.
- When preparing a version release, move the pending entries into the version section and keep `package.json` and `package-lock.json` versions consistent.
- Keep English `README.md` and `docs/README.zh-CN.md` usage instructions consistent when behavior changes.
